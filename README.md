# 🌐 Task 04 – Personal Portfolio Website

## 📌 Project Overview

This project is a modern and responsive **Personal Portfolio Website** created as part of my internship tasks.

The website is designed to showcase my:

- 👩‍💻 Skills
- 🚀 Projects
- 🎓 Learning journey
- 💡 Interests
- 📩 Contact information

The design follows a modern **Gen-Z inspired aesthetic** with dark backgrounds, neon accents, glassmorphism, animations, interactive elements, and a responsive layout.

---

## 🎯 Objective

The main objective of this task is to build a personal portfolio website that presents my skills, projects, achievements, and background in an attractive and professional way.

The website demonstrates the use of:

- HTML for website structure
- CSS for styling and responsive design
- JavaScript for interactivity and animations

---
